# ZMetrics Landing Page

Build a modern, responsive landing page for a Chrome extension called ZMetrics.

GOAL

Create a clean, professional, visually polished marketing website that explains the product very clearly with minimal text.

The product is a lightweight Chrome extension for tracking crypto prices quickly without leaving the current browser tab.

The page should feel:

- modern

- premium

- simple

- focused

- crypto-related but NOT flashy, scammy, noisy or meme-like

- closer to a professional productivity tool than a “trading casino”

IMPORTANT PRODUCT CONTEXT

ZMetrics is a Chrome extension that lets users:

- check crypto prices quickly

- see market cap

- see 24h change

- do it without switching tabs

- open a floating window with a keyboard shortcut

- customize tracked assets

- choose currency (USD / EUR)

The most important value proposition is speed and convenience.

DO NOT invent features that do not exist.

DO NOT invent testimonials, user counts, reviews, downloads, partner logos, investors, or pricing plans.

DO NOT make the product look like a crypto exchange.

DO NOT make it text-heavy.

DESIGN DIRECTION

Use a dark, sleek, modern interface.

The visual language should feel crisp and elegant, with:

- dark background

- subtle gradients

- soft glows used sparingly

- clean cards

- rounded corners

- strong spacing

- polished typography

- subtle animations / hover effects

- professional UI mockups

The page should look great on:

- desktop

- tablet

- mobile

STYLE REFERENCES

Think:

- startup landing page

- premium SaaS aesthetic

- modern product presentation

- minimal but expressive

Avoid:

- too much neon everywhere

- noisy trading charts as background

- clutter

- exaggerated “crypto bro” visuals

- too much copy

SITE STRUCTURE

Create these sections in this order:

1. NAVBAR

- ZMetrics logo / wordmark

- nav links: Features, Privacy

- primary CTA button: “Add to Chrome”

2. HERO SECTION

Main headline:

“Track crypto without leaving your tab.”

Supporting text:

“Live prices, market caps and 24h changes — always one click or shortcut away.”

Primary CTA:

“Add to Chrome”

Secondary CTA:

“See how it works”

Also show a subtle keyboard shortcut hint:

“Ctrl + Shift + Z” and optionally “⌘ + Shift + Z on Mac”

Visual:

A polished browser mockup showing a normal webpage with the ZMetrics extension popup visible on top.

The product should be immediately understandable in the hero.

3. FEATURE SECTION 1

Headline:

“Check the market without switching tabs.”

Supporting text:

“Check the prices you care about without opening another tab, dashboard or app.”

Visual:

A browser mockup with ZMetrics popup overlay.

Below or beside the mockup, show 3 small feature points:

- Live prices

- Market cap

- 24h change

4. FEATURE SECTION 2

Headline:

“One shortcut away.”

Supporting text:

“Pop out a floating window anytime and keep the market in view while you work, browse or trade.”

Visual:

Show the keyboard shortcut prominently:

“Ctrl + Shift + Z”

and a polished floating window mockup.

Also show 3 short supporting points:

- Open instantly with a shortcut

- Keep it visible while you browse

- Stay in your flow

5. FEATURE SECTION 3

Headline:

“Make it yours.”

Supporting text:

“Choose the assets you follow, reorder them, and switch between USD and EUR.”

Visual:

Show a settings-style mockup or UI cards illustrating:

- searching / adding assets

- reordering tracked assets

- currency selection (USD / EUR)

Keep this section very visual and concise.

6. PRIVACY SECTION

Headline:

“Built with privacy in mind.”

Supporting text:

“ZMetrics is designed to be useful without getting in your way. No noisy dashboards, no unnecessary complexity.”

Also include a short privacy-oriented note such as:

“Anonymous product analytics may be used to improve the extension, without collecting browsing history, wallets or personal data.”

Add a text link or button:

“Read Privacy Policy”

7. FINAL CTA SECTION

Headline:

“Track crypto without breaking your flow.”

Supporting text:

“Fast to open, easy to use, and always within reach.”

Primary CTA:

“Add to Chrome”

Optional secondary link:

“Read Privacy Policy”

8. FOOTER

Include:

- ZMetrics logo / wordmark

- link: Privacy

- link: X / Twitter

- short footer text such as:

“ZMetrics — Quick crypto tracking for Chrome.”

PAGES / ROUTES

Create at least:

- main landing page

- privacy page placeholder (/privacy)

The privacy page can be simple but should match the design system.

COPY / TONE

Keep text concise, confident and clear.

Do not over-explain.

Do not use hypey crypto language.

Do not sound corporate and generic.

Do not use long paragraphs.

VISUAL REQUIREMENTS

Use product mockups heavily.

The page should explain the product mostly through layout + visuals, not lots of text.

If exact screenshots are not available, create clean realistic UI mockups that are clearly inspired by a compact crypto tracker Chrome extension.

TECHNICAL / OUTPUT EXPECTATIONS

Generate a high-quality, production-style landing page with a reusable component structure.

Use clean layout hierarchy and consistent styling.

Make it feel like a real polished startup website.

IMPORTANT CONSTRAINTS

- No pricing section

- No testimonials

- No fake metrics

- No blog

- No login flow

- No unnecessary pages

- No giant walls of text

- No bright chaotic trading backgrounds

The final result should feel like:

“A simple but premium website for a useful Chrome extension.”

Use placeholder CTA links where needed:

- Add to Chrome -> #

- Privacy -> /privacy

- X / Twitter -> #

Make the design easy to adapt later to real links and real screenshots.

IMPORTANT — USE THE ATTACHED PRODUCT IMAGES

I have attached real screenshots of the ZMetrics Chrome extension.

Use them as the source of truth for:

- visual identity

- product UI

- colors

- spacing

- component style

- feature presentation

Do NOT redesign the extension UI inside the mockups.

Do NOT invent a different dashboard.

Do NOT replace the real product with a generic crypto interface.

Use the screenshots inside polished browser/device-style mockups when appropriate.

The website may have its own polished visual system, but it should feel visually coherent with the real ZMetrics extension shown in the attached images.
