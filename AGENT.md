# ZMetrics Video Motion Guide

This project should follow a premium motion language inspired by Apple product films and Phantom-style product marketing.

## Core rule

Nothing should feel frozen on screen unless that stillness is intentional and very brief.
If an element is the focus, it should usually keep a subtle sense of life through drift, breathing scale, glow evolution, parallax, or staged state change.

## Motion principles

- Prefer "materialize" transitions over hard cuts or flat fades.
- Treat related ideas as state changes in the same space before treating them as scene changes.
- Keep transitions clean, confident, and premium. No noisy UI micro-interactions.
- Use subtle ongoing motion after reveals so the video never feels stuck.
- Motion should be brief, precise, and purposeful.
- Avoid gratuitous animation that slows understanding.
- Motion should clarify hierarchy:
  - focus element moves most clearly
  - secondary elements drift more softly
  - background moves least

## Apple-like references to emulate

- Continuity between states
- Controlled camera-like push and pull
- Glass/light sweeps used sparingly
- Strong easing with smooth settle
- Product remains the hero at all times
- If motion happens often, keep it understated and lightweight
- Related UI changes should feel physically and visually connected

## Phantom-like references to emulate

- Dark premium atmosphere
- Floating product cards and layered depth
- Confident reveal timing
- Bold but clean contrast and glow

## Avoid

- Dead frames where everything appears stopped
- Generic fade-only transitions
- Random glows with no product logic
- Too many simultaneous effects
- Bouncy or playful motion that reduces the premium feel

## For this ZMetrics promo specifically

- The Chrome access block should feel like one continuous flow:
  - click
  - handoff
  - shortcut
- Popup, shortcut keys, and floating window should all retain subtle motion after appearing.
- Every transition should feel product-led, not template-led.
- Never leave a beat visually dead at the end of a sub-sequence; keep a small amount of intentional motion alive until the next handoff.

## Short-form ad rules for new vertical cuts

- Hook in the first second with the pain, not the feature.
- Make the problem legible instantly on mute.
- Show the product solving the problem as early as possible.
- Keep each beat focused on one idea only:
  - problem
  - instant access
  - personalization
  - shortcut
  - real workflow
  - CTA
- Prefer short, punchy copy over explanatory copy.
- Vertical-first framing:
  - product centered
  - text larger
  - fewer simultaneous elements
- Every 1 to 2 seconds, something meaningful should change:
  - new state
  - new proof
  - new reveal
  - new payoff
- Final CTA should feel like a product invitation, not a generic install ad.

## Source basis

- Apple Motion HIG: purpose, brevity, precision, continuity, and avoiding excessive repeated motion.
- Apple HIG hierarchy principles: product and focus should remain visually dominant.
- Google / YouTube creative guidance: brand and message should land early, with a clear visual story.
- TikTok creative guidance: first seconds must earn attention quickly, especially on mute.
- Meta Reels guidance: mobile-first framing and fast, clear storytelling outperform slower setup.
- Phantom reference is an inferred visual direction from the official Phantom homepage:
  - dark premium mood
  - layered depth
  - polished floating-card feel
